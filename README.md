# Fortune in a Pot

A fortune for a very loved houseplant: one perfect new leaf this week, photographed 214 times before breakfast.

## How it works

Stdlib-only `main.py` writes the entry (108 characters, no trailing newline) to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`).
